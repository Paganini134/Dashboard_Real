# Dashboard Real

A private-first daily goals dashboard for hygiene, fitness, nutrition, recovery,
spending, mindset, and accountability. It is built as a static GitHub Pages app
and stores entries locally in the browser with JSON/CSV export.

## Commands

```bash
npm install
npm run dev
npm run build
```

The production app is configured for GitHub Pages at `/Dashboard_Real/`.

## Data

- Entries save locally in your browser under a versioned dashboard key.
- Use the JSON export as the main backup and restore path.
- Use CSV export when you want to inspect the sheet in Excel or Google Sheets.
- The first tracking month is May 2026.
